🏡 Airbnb Investment Analysis - Asheville, NC
📌 Project Overview

This project analyzes Airbnb listings in Asheville, North Carolina to identify high-return investment opportunities in the short-term rental market.

The analysis supports data-driven real estate investment decisions using Tableau dashboards.

🎯 Business Objectives
Identify high ROI neighborhoods
Analyze property types and pricing patterns
Evaluate host performance and market saturation
Understand demand trends using review activity
Build an interactive investment decision tool
📊 Dashboards
1. Executive Summary Dashboard
Market overview (listings, price, availability)
ROI ranking of neighborhoods
Interactive filters and parameter controls
Map of listings
2. Deep Dive Dashboard
Host performance analysis
Property type comparison
Availability distribution
Amenities and supply insights
🧠 Key Metrics Used
Average price
Reviews per month (demand proxy)
Listing count (supply proxy)
Estimated revenue (price × demand)
ROI score (composite metric)
⚙️ Tools Used
Tableau Public
Excel / CSV dataset (Inside Airbnb)
Data cleaning & transformation
📈 Key Insights
Certain neighborhoods show high demand but moderate pricing → investment opportunity
Entire homes generate higher revenue but also higher competition
Host concentration indicates market dominance in specific areas
